# CHANGELOG

All notable changes to this project will be documented in this file.

## [0.0.1-alpha.1] - 2026-05-10

### Added

- **Initial Alpha Release**: Core security scanning engine for WordPress plugins.
- **Signature Engine**: Regex-based detection for PHP/JS vulnerabilities and malware.
- **AI Verification**: Optional verification layer using OpenAI-compatible models.
- **API Service**: FastAPI-based endpoint for remote scanning and integration.
- **Reporting Engine**: Generation of interactive HTML and structured JSON reports.
